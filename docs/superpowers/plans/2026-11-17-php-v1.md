# PHP v1 Language Slice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a conservative PHP v1 language slice to OXIDE v0.2.0 that produces declarations, imports, inheritance and cross-file references with four-way evidence, works for PHP-only and mixed PHP/HTML files, uses Composer autoload mappings, and is reachable through the existing navigation APIs and MCP surface.

**Architecture:** Mirror the C# slice: a query-driven syntax/facts extractor produces a cacheable `Parsed`; a Composer manifest reader supplies autoload evidence; a resolver builds a repo-wide FQN index and emits the common `Entity`/`Edge` shapes so no navigation or MCP code changes. Register `.php`/`.phtml` (and `.inc` only if capture evidence warrants it) in `core/indexing.py`.

**Tech Stack:** Python 3.12–3.14, `tree-sitter-php==0.25.1` (full PHP+HTML grammar), mypy `--strict`, Ruff, pytest, uv, Mise.

**Spec:** `docs/superpowers/specs/2026-11-17-php-v1-design.md`

## Global Constraints

- Pinned grammar: `tree-sitter-php==0.25.1`; keep `tree-sitter>=0.25,<0.27`. Version floors: Python `>=3.12,<3.15`; wheels must exist for macOS x86-64/arm64, manylinux + musllinux x86-64/arm64, win amd64/arm64.
- Every `src/oxide/**` file stays at or below 500 LOC (AGENTS.md). Split before completion if exceeded.
- No new MCP tools, no embeddings/judges, no execution of PHP or Composer, no network at index time.
- No changes to other languages' behavior, `FACTS_FORMAT` compatibility for existing dialects, or frozen baselines. Bump only PHP's own versions.
- Relation evidence uses the existing model: `Resolution = "resolved"|"ambiguous"|"unresolved"`, `Basis = "syntactic"|"resolved"|"heuristic"`. Four labels come from `lookup._label`: proven = resolved/resolved; heuristic = resolved/heuristic; ambiguous = ambiguous/syntactic; unresolved = unresolved/syntactic. Do not add a new field.
- Never emit a `calls` edge for a dynamic callee (variable function, variable method, `call_user_func*`, `call_user_func_array`, magic `__call`, reflection, string class names) or for an unsupported construct. Ambiguous and unresolved references are emitted with their source span; nothing is silently dropped.
- Entity keys: `symbol:<path>#<FQN with ".">` (e.g. `symbol:src/Store.php#App.Store`), modules `module:php:<dot-namespace>` (e.g. `module:php:App.Support`). `.` is required for navigation's qualified-name matching (`lookup._resolve` normalizes `::`→`.` and splits on `.`). Composer and source names stay in PHP's backslash form; convert at the boundary with `php_model.key_fqn(php_fqn: str) -> str` (`\` → `.`).
- Tests use private data locations; no test touches real user data. Conformance style: `derived()` + `resolved()` from `tests/python/test_typescript.py`.
- Capture is read-only (CAP-001); parse failure is never empty success (CAP-002); declarative-first with a stated gap analysis (CAP-003); deterministic snapshot-local identity (CAP-004); provenance and ambiguity retained (CAP-005).

## Review Focus

These five inputs are implied by the spec but no single happy-path test covers them; each has a test in the owning task.

1. **Mixed PHP/HTML** — a `.php`/`.phtml` file with inline HTML must yield only the declarations inside `<?php ... ?>`, with correct byte spans. → Task 2 `test_mixed_php_html_spans_are_inside_php_tags`.
2. **Dynamic callees** — `$fn()`, `$obj->$m()`, `call_user_func(...)`, `$obj->__call(...)` must produce no `calls` edge, while `$this->m()` and `self::m()` may produce one. → Task 7 `test_dynamic_calls_emit_no_edges`.
3. **Composer prefix rules** — trailing `\` is significant; longest matching PSR-4 prefix wins; PSR-0 keeps the prefix in the path. → Task 4 `test_longest_psr4_prefix_wins_and_trailing_slash_is_significant`.
4. **Alias vs namespace** — two classes with the same short name in different namespaces, imported via `use A\X as Y` and `use B\X`, must resolve to distinct symbols; an unimported duplicate stays ambiguous. → Task 5 `test_aliases_and_current_namespace_do_not_collapse`.
5. **Partial parse** — a file with a syntax error must carry diagnostics and `partial` coverage, never an empty `complete` result. → Task 3 `test_partial_parse_reports_diagnostics_not_empty_success`.

```python
# php_model.py
@dataclass(slots=True)
class Decl:
    kind: str          # function|method|class|interface|trait|enum|constant|case|property
    name: str          # simple name
    start: int
    end: int
    signature: str
    ns: str            # dot-joined namespace, "" for global
    parent: int | None # index into Parsed.decls, None at top level

@dataclass(frozen=True, slots=True)
class Import:
    kind: str          # class|function|const|group
    path: str          # backslash-joined FQN/prefix
    alias: str         # "" when absent
    ns: str
    start: int
    end: int

@dataclass(frozen=True, slots=True)
class Use:
    name: str          # backslash-joined or simple name as written
    start: int
    end: int
    owner: int | None  # declaration index owning this reference
    kind: str          # ""|extends|implements|trait

@dataclass(frozen=True, slots=True)
class Call:
    name: str          # as written, e.g. "Logger::write", "$this->find", "build"
    start: int
    end: int
    owner: int | None
    kind: str          # function|static|method|new

@dataclass(slots=True)
class Parsed:
    decls: list[Decl]
    imports: list[Import]
    bases: list[Use]
    refs: list[Use]
    calls: list[Call]
    diagnostics: list[str]
    namespaces: list[tuple[int, int, str]]  # (start, end, namespace)

def symbol_key(path: str, fqn: str) -> str: ...  # fqn "\".replace→"."
def fqn(decl: Decl, decls: list[Decl]) -> str: ...  # enclosing classes + ns + name
```

`php_syntax.py` provides `text`, `span`, `name`, `qualified`, `namespace_at`, `is_php_tag` helpers; all take `(data, node)` and return `str`/`None`/tuples.

`php.parse(data: bytes) -> Parsed | str` replaces the stub. It decodes UTF-8 (return `"PHP source is not UTF-8"` on failure), parses with `Parser(LANGUAGE)`, rejects `too_deep(root)`, runs one compiled `Query` plus `_BROKEN`, and returns `Parsed` with sorted lists.

**Files:**

**Interfaces:**
- Consumes: captured `composer.json` bytes from `derive`'s `others` mapping (built in Task 5) or directly from `capture()` in tests.
- Produces:

```python
@dataclass(frozen=True, slots=True)
class Composer:
    rules: tuple[tuple[str, str, str], ...]  # (style, prefix, root_dir), style psr4|psr0
    classmap: tuple[str, ...]
    files: tuple[str, ...]

def load(manifests: Mapping[str, bytes]) -> Composer: ...
def fqn_at(composer: Composer, path: str) -> tuple[str, str] | None:  # (style, FQN) inferred from path
def path_for(composer: Composer, fqn: str) -> tuple[str, str] | None:  # (style, path) inferred from FQN
def classmap_roots(composer: Composer) -> tuple[str, ...]: ...
```

Prefixes keep their trailing `\` internally; roots are repo-relative POSIX paths derived from the `composer.json` directory. `load` reads `autoload` and `autoload-dev`, accepts string or array values, ignores malformed JSON (returns empty `Composer`) and never executes anything. `fqn_at`/`path_for` choose the **longest** matching prefix; for `psr4` the prefix is stripped from the path/FQN, for `psr0` it is not.

- Consumes: `php_sources` from Task 3; `Composer` from Task 4; `php_model.fqn`, `symbol_key`; `python_resolve.Edge`, `edge_target`, `structural`.
- Produces:

```python
class Resolver:
    def __init__(self, sources: list[tuple[str, str, php_model.Parsed]],
                 composer: php_composer.Composer) -> None: ...
    def derive(self, entities: list[Entity], edges: list[Edge]) -> None: ...
```

Index: FQN (dot form) → candidate symbol keys. Resolution order, each step stopping at the first result:
1. leading `\` → exact FQN (proven);
2. alias from the enclosing namespace's `Import` → target FQN (proven if found);
3. current namespace + name (proven if unique, ambiguous if >1);
4. Composer PSR-4/PSR-0 `path_for(FQN)` where the path is captured (proven, file-level target);
5. Composer classmap root (heuristic);
6. global name (heuristic if unique, ambiguous if multiple, else unresolved).

Calls with `kind == "static"` or `"method"` resolve their class part through the same pipeline and then look for the method on that class's captured scope (including captured `extends`/`implements`/traits). An unresolvable receiver yields an unresolved edge with the written name; a dynamically-shaped callee from Task 2 never appears. `php_emit.derive` emits modules, `contains`/`contains_logical`/`defines`, imports, references and calls with `SourceRef` evidence from every `Use`/`Call`.
