## Displaced previously-good budgeted files (regression with aggressive file_lex)
- e.g., pylint/checkers/similar.py, flask/blueprints.py, ansible modules — these were top3 hybrid primaries with strong symbol scores (lexical 230+). After file-lex aggressive (weight 0.35 limit5), 5 file reps with lexical:file 190-241 were injected as RRF candidates with weight 0.35/(60+rank) ≈ 0.005-0.006, enough to push them above some legit primaries due to RRF tie-breaking plus role ordering (file reps were inserted as primaries). Their snippets were __module__-like, low value, displaced good primaries out of budgeted top6.
- Classification for regressions: (4) file score too authoritative relative to symbol evidence, plus (3) allocator treats file reps as primaries (same role as seeds) so one weak generated representative displaces a known-good primary, and (1) wrong rep amplifies.

## Summary classification
- Wrong representative symbol: YES for all 6 (file→__module__ or generic class, not dense region). Even best-symbol-by-lexical picks __module__ for 2/4 measured, not the densest method.
- Relevant evidence outside symbol boundaries: NO — evidence is inside function/method/class for 5/6 (buckets show inside method/function dominates). Module-level only ~10-20%. So evidence IS inside indexed symbols, but per-symbol BM25 is too weak to rank.
- Allocator role ordering: YES for 2/6 (test file) and for regressions (file reps crowding).
- File score too authoritative: YES for regressions (weight 0.35 with limit5 pushes 5 weak files into top10).
- Combination: YES — primary failure is (1)+(2)+(4)+(3) together. File lexical discovery is correct (strong signal), but canonicalizing to one arbitrary representative symbol loses the localized evidence and allocator treats it as high-authority primary.

## Does bounded query-centered window contain gold?
- All 4 precisely measured rescues: YES — densest 60-line window contains 22-30 term hits and overlaps gold symbol region (Plot methods, _DistributionPlotter, VariablesChecker, get_module_and_frameid). So deterministic lexical windowing would capture useful evidence.
- Expected for remaining 2 (requests, pytest): YES based on file length and hit density.

- Forensic shows localizable evidence (dense clusters inside real symbols). So Phase2 file→span experiment is justified. Must not reuse old representative-symbol path.
